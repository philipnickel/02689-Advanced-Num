# 02689-Advanced-Num

## Environment setup

1. Create a virtual environment in the repo root:
   ```bash
   python3 -m venv .venv
   ```
2. Activate it and install the requirements (repeat after pulling changes):
   ```bash
   source .venv/bin/activate
   pip install -r requirements.txt
   ```
3. Run assignment scripts as modules from the repository root so package imports resolve automatically, e.g.:
   ```bash
   python -m assignment_1.FourierSpectralMethods.exercise_a
   ```
