# 02689-Advanced-Num

Advanced Numerical Algorithms - DTU Course 02689

## Setup

Install uv and dependencies:
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
uv sync
```

## Running Exercises

```bash
uv run python assignment_1/FourierSpectralMethods/exercise_a.py
```

## Dependencies

- numpy, matplotlib, scipy, scienceplots, numba, sympy
